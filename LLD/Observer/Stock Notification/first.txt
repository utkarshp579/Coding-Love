Problem:

Stock price changes → notify users via multiple channels.

What you code:

Create a class like:

StockPriceNotifier

Inside it:

Method: updatePrice(price)
Hardcode:
Email notification
SMS notification
App notification
Example structure (don’t copy, build yourself):
EmailService.send()
SMSService.send()
AppService.send()

And in StockPriceNotifier:

if price changes:
    call email
    call sms
    call app
Why this is trash (you must feel this)

After coding, ask yourself:

What if I want to add WhatsApp notifications?
What if one user only wants SMS?
What if 1000 users subscribe/unsubscribe dynamically?
