DRY (Don't Repeat Yourself): This principle encourages minimizing code duplication. 
    Instead of repeating logic, abstract it into reusable functions or modules. 
    This makes code easier to maintain and reduces errors.
YAGNI (You Aren't Gonna Need It): Only implement features or code when they are actually required. 
    Avoid adding functionality "just in case," as it increases complexity and maintenance without real benefit.
KISS (Keep It Simple, Stupid): Strive for simplicity in design and implementation. 
    Simple solutions are easier to understand, maintain, and debug. Avoid unnecessary complexity or overengineering.
